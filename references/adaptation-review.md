# Adaptation Review

Use this reference for scales adapted from mature sources into AI, leadership, team, work-task, or paired survey contexts.

## Reviewer-defensibility questions

For each adapted item, answer:

1. What is the original item's core behavior, cognition, emotion, or evaluation?
2. What exactly changed: object, referent, actor, context, valence, time frame, or response perspective?
3. Does the adapted item preserve the original measurement logic?
4. Does the adaptation introduce a new construct, antecedent, outcome, value judgment, or causal claim?
5. Can the method section explain the change as an adaptation rather than new scale development?
6. If back-translated, would the adapted Chinese still resemble the source item, or would it read like a new item?
7. Does the adaptation preserve the source scale's level of analysis and respondent perspective?

## Adaptation risk levels

| Level | Meaning | Report language |
|---|---|---|
| 可直接解释 | Only object/context changed and construct logic is preserved | "可作为合理情境改编" |
| 需要补充解释 | Adaptation is plausible but should be explained in method/appendix | "建议说明替换逻辑" |
| 需要谨慎 | Psychological meaning changed or new assumptions introduced | "可能被审稿人质疑为近似自编" |
| 建议重写或另找量表 | Original logic no longer supports adapted item | "建议重新寻找量表或按自编量表处理" |

## Common adaptation changes

| Change | Example | Check |
|---|---|---|
| Object replacement | technology -> AI | Is AI defined broadly enough? |
| Actor replacement | top managers -> direct supervisor | Does level of analysis change? |
| Referent replacement | group members -> employees/subordinates | Is the respondent able to observe this? |
| Perspective change | self-report -> leader-rated employee | Are pronouns and evidence basis clear? |
| Valence change | good fit -> misfit | Is positive/negative direction consistent? |
| Added item | New global or context-specific item | Explain why it belongs and mark as new/adapted |

## Back-translation stress test

For high-value adapted scales, mentally back-translate the Chinese into English. If the result would not recover the source item's main verb, object, actor, and intensity, flag the item.

Examples of high-risk drift:

- `make an effort to convince managers of the benefits` -> `会努力让我们相信 AI 带来的好处`: plausible but actor, target, and technology context all changed; explain the replacement from top managers/managers to direct supervisor/subordinates.
- `I work with my group members to create...` -> `营造了一种...氛围`: changes a concrete joint behavior into a broad climate perception.
- `My abilities and training are a good fit...` -> `AI 的功能并不契合...`: changes person-job fit into AI-task misfit and reverses valence; treat as high adaptation, not simple translation.

## Method-writing support

When reporting adapted scales, draft concise Chinese notes that can later be turned into English method text:

- Source scale and construct.
- Adaptation target and rationale.
- Wording replacement logic.
- Reverse-coded source item positive wording, if any.
- New or substantially rewritten items, if any.
- Need for pretest/back translation/expert review, if high adaptation.
