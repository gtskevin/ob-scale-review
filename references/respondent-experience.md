# Respondent Experience Checks

Review as if the respondent is a busy employee or manager in a Chinese enterprise.

## Ambiguity checks

| Ambiguous expression | Possible interpretations | Preferred action |
|---|---|---|
| 我所在的团队 | coworker team, department, project team, or subordinates | Specify 工作小组/部门/我所管理的团队 |
| 部门/本部门 | direct work team, formal department, business unit, or whole company | Specify 该员工所在工作小组/我直接管理的团队/正式部门 |
| 领导 | direct supervisor, senior manager, company leaders | Specify 我的直属领导 or 公司高层管理者 |
| AI | ChatGPT only, internal AI system, automation, analytics tools | Define AI tools in instructions |
| 近期 | last week, last month, since prior survey | Use concrete wave/date window |
| 工作表现 | self-perceived, leader-rated, objective KPI | Match respondent and source |
| 他人 | colleagues, supervisor, subordinates, clients | Specify when meaningful |
| 我们 | respondent plus coworkers, whole team, or all subordinates | Use 我 if individual-level; use 团队成员/下属 if collective referent is intended |

## Instruction and demand-characteristic checks

Questionnaire instructions should help respondents answer, not teach them the study's construct definition.

Flag instructions that:

- Name or define the latent variable in detail before the items.
- Explain the distinction between the focal construct and nearby constructs in a way that reveals the researcher's intention.
- Tell respondents what the scale is intended to measure.
- Use long academic phrases that respondents may not naturally use.

Safer instructions usually include only:

- The target object, such as `您的直属领导`, `您本人`, or `您直接评价的下属`.
- The time window.
- The response anchor.
- A minimal everyday definition for ambiguous tools such as AI.

Example: `这里关注的是AI工具本身能否处理您工作中的核心要求，而不是您是否擅长使用AI...` may help distinguish constructs for researchers, but it can prime respondents and reveal the variable logic. Consider shortening it to a neutral task description.

## Referent and level-of-analysis checks

For leadership and team research, pronouns can change the construct.

- `我的领导经常劝我...` points to the respondent's individual experience.
- `我的领导经常劝我们...` points to a shared/team-level target or the leader's general behavior toward a group.
- `该员工对本部门的贡献很大` depends on what the leader treats as `本部门`; use a defined work unit if performance is rated relative to a specific team.

Flag these as method issues, not only wording issues. The report should tell the researcher to align item referents with the intended level of analysis and aggregation plan.

## Paired and multi-wave survey checks

- Employee and leader versions must have clear respondent labels.
- Pairing ID instructions must be present if pairing is required.
- Leader-rated items must identify the employee and time window without exposing sensitive employee answers.
- T1/T2/T3 variable placement should match the variable list.
- Avoid measuring outcomes before predictors when the study design depends on temporal separation.
- Replace launch placeholders such as `XX`, `x月x日`, `某某`, `name of school`.

## Response option checks

- Agreement: use for attitudes, perceptions, beliefs.
- Fit/conformity: use for "describes my situation" wording.
- Frequency: use for repeated behaviors and experiences.
- Do not mix frequency wording with agreement anchors unless intentional and clear.
- Keep 1-5 direction consistent within the survey.

## Sensitive items

For impression management, exaggeration, facades of conformity, unethical behavior, or politically sensitive items:

- Reduce moralizing language when possible.
- Add anonymous/confidential framing in instructions.
- Avoid wording that sounds like accusation.
- Consider indirect or behaviorally specific wording.
